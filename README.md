# 🛒 Rubel Mart Frontend

Modern, scalable, and high-performance e-commerce frontend built with Next.js, React, TypeScript, Tailwind CSS, and Shadcn UI.

**Rubel Mart** is designed to provide a seamless shopping experience with modern UI/UX, responsive layouts, optimized performance, dark/light theme support, and a scalable architecture suitable for enterprise-grade e-commerce applications.

> Smart Shopping For Modern Living

---

## 🚀 Tech Stack

### Core Framework

- Next.js 16

- TypeScript

- Tailwind CSS v4
- Shadcn UI
- CSS Variables Theming

## 🔒 Backend Integration

This repository contains only the frontend application.

The backend is maintained in a separate repository and provides:

- Authentication
- Product Management
- Category Management
- Cart Management
- Wishlist Management
- Order Processing
- Payment Integration
- Inventory Management
- User Management

Frontend communicates with the backend via REST APIs.
